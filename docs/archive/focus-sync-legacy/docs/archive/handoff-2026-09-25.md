## 五、关键决策与坑

1. **fork 改动要带 `[fork-keep]` 注释**(commit message 前缀 + 代码块注释),未来 sync 时易识别
2. **不要碰 `src-tauri/` Rust 端代码**(能力/权限配置、签名流程禁区)
3. **vitest 单跑无问题,但 `run-p` 并行跑 154 文件偶发 5s timeout**,这是基础设施问题不是我的代码,看到 1 个超时不用慌,先 `npx vitest run <file>` 单独验证
4. **vite-plugin-run 会自动同步 i18n**:en.json 改动后会通过 `scripts/sync-i18n.js` 把 keys 写到其他 locale,这是项目内置,不要回滚意外的 locale 改动
5. **扩展 `UserSettings` 类型字段前先确认**:若测试用 partial mock,加新 required 字段可能让 mock 缺字段;TypeScript 编译能过但 runtime 可能不稳
