## 2. L1 根因确认(独立验证 Mavis)

### 2.1 位置精确定位

**文件**:`sigma-file-manager/src-tauri/src/extensions/extension_http.rs`

**第 26-38 行**(关键):
```rust
fn extension_http_client() -> Result<&'static reqwest::Client, String> {
    EXTENSION_HTTP_CLIENT
        .get_or_init(|| {
            reqwest::Client::builder()
                .connect_timeout(Duration::from_secs(15))
                .redirect(reqwest::redirect::Policy::limited(5))
                .user_agent(HTTP_USER_AGENT)
                .build()                                                          // ❌ 缺 .no_proxy()
                .map_err(|error| format!("Failed to create HTTP client: {}", error))
        })
        .as_ref()
        .map_err(|error| error.clone())
}
```

**问题**:`reqwest::Client::builder()` 没有调用 `.no_proxy()`

### 2.2 reqwest 0.13 默认行为

**来源**:`Cargo.toml` 确认 reqwest 0.13
```toml
reqwest = { version = "0.13", default-features = false, features = ["rustls", "stream"] }
```

**reqwest 0.13 文档行为**(基于公开文档和实际验证):
- 默认读 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` 环境变量
- **不读 `NO_PROXY`**(除非显式 `.no_proxy()`)
- 没有 `.no_proxy()` 时,**所有 HTTP 请求都走 proxy**,即使目标是 `localhost` / `127.0.0.1`

### 2.3 本机环境验证(Mavis 跑的实际命令)

```powershell
PS> [Environment]::GetEnvironmentVariable('HTTPS_PROXY', 'Process')
http://127.0.0.1:7897
PS> [Environment]::GetEnvironmentVariable('HTTP_PROXY', 'Process')
http://127.0.0.1:7897
PS> [Environment]::GetEnvironmentVariable('NO_PROXY', 'Process')
localhost,127.0.0.1,::1
```

**状态**:
- ✅ `HTTPS_PROXY` 已设置 = `http://127.0.0.1:7897`(典型 clash/clash-verge/mihomo 端口)
- ✅ `NO_PROXY` 已设置(包含 localhost / 127.0.0.1)= **没用,reqwest 不读**
- ✅ `HTTP_PROXY` 已设置

### 2.4 用户截图直接证据

**Sigma FM DevTools 控制台**(用户截图):

```

[focus-sync] onPathChange raw="C:/downloads"
```

**5 种路径,11 次 PUSH,全部 502**。

### 2.5 综合证据链

1. ✅ Sigma FM sandbox (`extension_http.rs`) 创建 reqwest client **没有** `.no_proxy()`
2. ✅ reqwest 0.13 默认读 `HTTPS_PROXY=http://127.0.0.1:7897`
3. ✅ 所有 extension HTTP 请求(包括 `http://127.0.0.1:37421/set_path`)被 reqwest 路由到 proxy `127.0.0.1:7897`
4. ✅ 用户本机 proxy 服务(端口 7897)实际行为:
   - 接受 TCP 连接
   - 但对某些请求返回 502(具体行为取决于 proxy 软件)
5. ✅ sidecar 直接 curl 验证返回 200(sidecar 完全正常)
6. ✅ grep 验证 sidecar 端无 502 生成路径

**结论**:**L1 根因完全成立,PUSH 永远 502,sidecar 永远收不到 path**。

## 4. v0.3.7 修复方案(L1 + 沿用 v0.3.6)

### 4.1 🔴 Fix L1: `extension_http.rs` 加 `.no_proxy()`

**文件**:`sigma-file-manager/src-tauri/src/extensions/extension_http.rs`
**第 26-38 行**改为:

```rust
fn extension_http_client() -> Result<&'static reqwest::Client, String> {
    EXTENSION_HTTP_CLIENT
        .get_or_init(|| {
            reqwest::Client::builder()
                .connect_timeout(Duration::from_secs(15))
                .redirect(reqwest::redirect::Policy::limited(5))
                .user_agent(HTTP_USER_AGENT)
                // focus-21 v0.3.7 (Mavis review L1): honor system NO_PROXY.
                // Without this, reqwest routes all requests through
                // HTTPS_PROXY/HTTP_PROXY (set by Clash/mihomo/cowboy etc.),
                // even for localhost / 127.0.0.1 targets. Result: every
                // focus-sync PUSH to http://127.0.0.1:37421 gets proxied,
                // the proxy returns 502 (or times out), the extension sees
                // "PUSH response status=502", and sidecar never receives
                // the path → dialog never navigates. Per
                // docs/superpowers/plans/2026-10-03-focus-21-v0.3.7-L1-review.md
                // §2 (Mavis 8th-round review of Claude systematic-debugging).
                .no_proxy()
                .build()
                .map_err(|error| format!("Failed to create HTTP client: {}", error))
        })
        .as_ref()
        .map_err(|error| error.clone())
}
```

**关键改动**:`.user_agent(HTTP_USER_AGENT)` 之后加 `.no_proxy()`

**为什么 `.no_proxy()` 就够**:
- reqwest 0.13 文档:`.no_proxy()` 让 client 读 `NO_PROXY` 环境变量
- `NO_PROXY=localhost,127.0.0.1,::1`(本机已设置)→ localhost / 127.0.0.1 / ::1 请求绕过 proxy
- 其他 host 仍走 `HTTP_PROXY`/`HTTPS_PROXY`(保持扩展的 http 网络能力)
