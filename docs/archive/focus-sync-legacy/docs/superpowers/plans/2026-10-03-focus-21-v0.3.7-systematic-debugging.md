## 2. v0.3.7 修复方案

### 2.1 🔴 P0 Fix L1: `extension_http.rs` 加 `.no_proxy()`

**位置**:`sigma-file-manager/src-tauri/src/extensions/extension_http.rs` 第 26-38 行(具体是第 32 行 `user_agent(HTTP_USER_AGENT)` 之后)

**当前代码**(我已读过):
```rust
fn extension_http_client() -> Result<&'static reqwest::Client, String> {
    EXTENSION_HTTP_CLIENT
        .get_or_init(|| {
            reqwest::Client::builder()
                .connect_timeout(Duration::from_secs(15))
                .redirect(reqwest::redirect::Policy::limited(5))
                .user_agent(HTTP_USER_AGENT)              // ← L1: 这里之后加 .no_proxy()
                .build()
                .map_err(|error| format!("Failed to create HTTP client: {}", error))
        })
        .as_ref()
        .map_err(|error| error.clone())
}
```

**v0.3.7 修复**:
```rust
fn extension_http_client() -> Result<&'static reqwest::Client, String> {
    EXTENSION_HTTP_CLIENT
        .get_or_init(|| {
            reqwest::Client::builder()
                .connect_timeout(Duration::from_secs(15))
                .redirect(reqwest::redirect::Policy::limited(5))
                .user_agent(HTTP_USER_AGENT)
                // focus-21 v0.3.7 (Mavis 8th-round L1 review): honor system
                // NO_PROXY. Without this, reqwest 0.13 routes ALL requests
                // through HTTPS_PROXY/HTTP_PROXY (clash/mihomo/cowboy etc.),
                // even for localhost/127.0.0.1 targets. Result: every
                // focus-sync PUSH to http://127.0.0.1:37421 gets proxied,
                // the proxy returns 502, the extension sees
                // "PUSH response status=502", and sidecar never receives
                // the path → dialog never navigates. NO_PROXY=localhost,
                // 127.0.0.1,::1 is already set in user env (Mavis §2.3).
                .no_proxy()
                .build()
                .map_err(|error| format!("Failed to create HTTP client: {}", error))
        })
        .as_ref()
        .map_err(|error| error.clone())
}
```

**关键改动**:`.user_agent(HTTP_USER_AGENT)` 后加 `.no_proxy()`,**仅 1 行**。

**为什么 `.no_proxy()` 就够**:
- reqwest 0.13 文档:`.no_proxy()` 让 client 读 `NO_PROXY` 环境变量
- 本机 `NO_PROXY=localhost,127.0.0.1,::1` 已设置 → localhost/127.0.0.1/::1 请求绕过 proxy
- 其他 host 仍走 `HTTP_PROXY`/`HTTPS_PROXY`(扩展的 http 网络能力不变)
