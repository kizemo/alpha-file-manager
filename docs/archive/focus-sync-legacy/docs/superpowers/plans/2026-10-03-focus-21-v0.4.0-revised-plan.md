### 2.3 改动 C:新增 `find_navigation_address_bar` helper(**C4 修正版**)

**位置**:`uia_inject.rs`,紧跟 `find_ifiledialog_edit` 之后

```rust
/// v0.4.0 (C4 revised): locate the navigation address bar / breadcrumb /
/// search box in a dialog tree.
///
/// C4 修正:Chromium 41477 已在 inject_via_uia 主流程的 41477 分支处理,
/// 1001/1148 是 filename Edit(由 find_ifiledialog_edit 单独处理)。
/// 所以这里**排除**这三个 automation_id,只寻找"非 filename、非 41477"
/// 的导航控件。
///
/// 匹配规则(优先级顺序):
/// 1. Edit ControlType + name 含 "地址"/"路径"/"位置"/"address"/"path"/"location"
/// 2. Edit ControlType + name 含 "search" (search box 经常接受路径输入)
/// 3. SearchEditBox(已包含 search 匹配,这里保留作 fallback)
///
/// 返回第一个匹配的 Edit 元素。如果整个 dialog 树没有 address bar,返回 None,
/// 由调用方走 Unsupported fallback(规则 36:真正不污染 = 不动)。
fn find_navigation_address_bar(
    elements: &IUIAutomationElementArray,
) -> Option<IUIAutomationElement> {
    let count = unsafe { elements.Length() }.ok()?;
    for i in 0..count {
        let element = unsafe { elements.GetElement(i).ok()? };
        // C4 [MEDIUM]: skip known-handled automation IDs
        let aid = current_automation_id(&element);
        if aid == "41477" || aid == "1001" || aid == "1148" {
            continue;
        }
        let ct = unsafe { element.CurrentControlType().ok()? };
        if ct != UIA_EditControlTypeId {
            continue;
        }
        // Generic address bar / search box by name
        let name = current_name(&element).to_lowercase();
        let is_navigation = name.contains("地址")
            || name.contains("路径")
            || name.contains("位置")
            || name.contains("address")
            || name.contains("path")
            || name.contains("location")
            || name.contains("search");  // search box often accepts paths
        if is_navigation {
            return Some(element);
        }
    }
    None
}
```

### 2.4 改动 D:WinUI 3 wrapped 分支(**C1 + C2 + C5 + C6 全部修正**)

**位置**:`uia_inject.rs` `inject_via_uia` 函数,在 address_bar 分支之后、find_ifiledialog_edit 分支之前

```rust
// v0.4.0 (C1 + C2 + C5 + C6 revised): WinUI 3 wrapped dialog handling.
//
// Rule 36 (Mavis 第 12 轮): 真正"不污染" = 完全不动 filename Edit。
// 用户原本 filename = "WeavePage_3.0.0_x64-setup.exe",我们不写任何东西到
// filename Edit(不写完整路径,不写 basename,什么都不写)。
//
// 检测:FileNameControlHost (Pane 50003) 存在 = WinUI 3 wrapped。
// 注意:1001 Edit 在 WinUI 3 wrapped dialog 里也存在(内嵌 IFileDialog),
// 但我们**不调用 find_ifiledialog_edit**,因为那会污染 filename。
let has_filename_host = {
    let count = unsafe { elements.Length() }.ok().unwrap_or(0);
    (0..count).any(|i| {
        unsafe { elements.GetElement(i).ok() }
            .map(|e| current_automation_id(&e) == "FileNameControlHost")
            .unwrap_or(false)
    })
};

if has_filename_host {
    // C1 [HIGH]: WinUI 3 wrapped — DO NOT touch filename Edit at all.
    // 任何 SetValue 到 1001/1148 都是污染(basename 也算)。
    info!(
        "v0.4.0: WinUI 3 wrapped dialog detected (FileNameControlHost present). \
         Leaving filename Edit untouched. Trying navigation address bar. \
         target='{target_path}'"
    );

    // 尝试找 navigation address bar (search box / address bar / breadcrumb)
    match find_navigation_address_bar(&elements) {
        Some(addr_bar) => {
            // C2 [HIGH]: SetValue 后必须 read back verify (v0.3.8 A2 风格)
            let addr_value: IUIAutomationValuePattern = unsafe {
                addr_bar.GetCurrentPatternAs(UIA_ValuePatternId)?
            };
            unsafe { addr_value.SetValue(&BSTR::from(target_path))? };
            let readback = unsafe { addr_value.CurrentValue() }?;
            let readback_str = readback.to_string();

            if !path_matches(&readback_str, target_path) {
                // C2: verification failed — silently rejected, notify user
                warn!(
                    "v0.4.0: address bar SetValue verification FAILED. \
                     Wrote='{target_path}', Read back='{readback_str}'. \
                     WinUI 3 may be blocking. Notify user to navigate manually."
                );
                state.inc_unsupported_dialog();
                return Ok(DialogOutcome::Unsupported);
            }
            info!(
                "v0.4.0: WinUI 3 wrapped — wrote target='{target_path}' to \
                 navigation address bar (read-back verified). \
                 filename Edit untouched."
            );
            // C6 [MEDIUM]: WinUI 3 wrapped branch does NOT Auto-Commit.
            // Reason: filename 字段未变,dialog 顶部路径栏已更新,
            // 但 WinUI 3 Save button 可能不响应外部 Invoke。让用户手动 Save
            // 确保他们看到 dialog 状态变化。
            return Ok(DialogOutcome::AddressBarWritten);
        }
        None => {
            // C5: 无 address bar,完全不动 filename
            warn!(
                "v0.4.0: WinUI 3 wrapped — no navigation address bar found. \
                 Cannot navigate without polluting filename. User must navigate \
                 manually. target='{target_path}'"
            );
            state.inc_unsupported_dialog();
            return Ok(DialogOutcome::Unsupported);
        }
    }
}
```
