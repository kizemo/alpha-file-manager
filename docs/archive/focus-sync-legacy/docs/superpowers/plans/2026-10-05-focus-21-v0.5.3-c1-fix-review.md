## 3. 🟡 O2 — `Vec::with_capacity` 容量计算错误

### 3.1 问题

**plan §1.1 line 91-92**:
```rust
let mut inputs: Vec<INPUT> =
    Vec::with_capacity(8 + target_path.encode_utf16().count() * 2);
```

### 3.2 实际 push 数量

| 段 | events | 说明 |
|---|---|---|
| Ctrl+L | 4 | Ctrl↓ + L↓ + L↑ + Ctrl↑ |
| Home+Shift+End | 6 | Home↓ + Home↑ + Shift↓ + End↓ + End↑ + Shift↑ |
| path chars | N × 2 | N 个 char,每个 press + release |
| **总计** | **10 + 2N** | — |

但 plan 写 `8 + 2N`,**少算 2**。

### 3.3 后果

Vec 预留 8 + 14 = 22 slots(C:\evid),实际 push 24。Vec 在第 23 个 push 时 realloc 一次,触发额外内存分配。

**性能影响**:一次 realloc,~几十 ns。**实际无影响**。

### 3.4 修复建议

```diff
- let mut inputs: Vec<INPUT> =
-     Vec::with_capacity(8 + target_path.encode_utf16().count() * 2);
+ let mut inputs: Vec<INPUT> =
+     Vec::with_capacity(10 + target_path.encode_utf16().count() * 2);
```

**或者**(更简单):
```rust
let mut inputs: Vec<INPUT> = Vec::new();
// 让 Vec 自动 grow,无需预留
```

但预留 10 + 2N 是合理优化。

### 3.5 文档与代码一致性

**plan §2.3 表格**(line 230-232):
| path | 非-path events | path events | 总计 |
|---|---|---|---|
| **C:\evid (7)** | 4 + 6 = 10 | 14 | **24** |
| **C:\downloads (12)** | 10 | 24 | **34** |
| **C:\boost_weasel (15)** | 10 | 30 | **40** |

**表格**说 10 + 2N,但 **代码** 写 8 + 2N。**文档/代码不一致**。

修复:让代码与文档一致。

## 4. ⚪ O3 — AllowSetForegroundWindow(ASFW_ANY) 在 sidecar 中无效

### 4.1 MSDN 语义

> "The foreground process can call AllowSetForegroundWindow to enable the specified process to set the foreground window."

**前置条件**:**AllowSetForegroundWindow 必须由 FOREGROUND process 调用**。

### 4.2 plan 调用

```rust
let _ = AllowSetForegroundWindow(ASFW_ANY);
```

sidecar(spike.exe)调用此函数。但 sidecar 不是 foreground process(Sigma FM 是 foreground)。

### 4.3 实际效果

Windows 拒绝此调用(per MSDN)— 但**不会报错**:
- 函数返回 `Result<()>`,但 BOOL 内部转换丢弃了"no-op"信号
- 实际等同 no-op

### 4.4 是否需要删除?

**不建议删**:
- 删除需要改 1 行(违反最小化)
- 保留无害(no-op)
- 未来如果 sidecar 真成为 foreground(例如切换到 main thread),这调用立即 work
- **保留作为 defensive code**

### 4.5 是否需要 log warn?

plan §1.1 line 79 没有 log this call。可以加,但**不是必要**。

### 4.6 综合判断

**接受 plan 的当前写法**。O3 是 informational warning,非阻塞。

### 6.2 函数体

```rust
fn try_send_path_via_sendinput(dialog_hwnd: u32, target_path: &str) -> bool {
    let hwnd = HWND(dialog_hwnd as *mut core::ffi::c_void);
    unsafe {
        let _ = AllowSetForegroundWindow(ASFW_ANY);
        let _ = SetForegroundWindow(hwnd);
        let current_fg = GetForegroundWindow();
        if current_fg != hwnd {
            warn!("...");
        }

        let mut inputs: Vec<INPUT> = Vec::with_capacity(8 + target_path.encode_utf16().count() * 2);
        inputs.push(make_key(VK_CONTROL.0, 0));
        inputs.push(make_key(VK_L.0, 0));
        inputs.push(make_key(VK_L.0, KEYEVENTF_KEYUP.0));
        inputs.push(make_key(VK_CONTROL.0, KEYEVENTF_KEYUP.0));

        inputs.push(make_key(VK_HOME.0, 0));
        inputs.push(make_key(VK_HOME.0, KEYEVENTF_KEYUP.0));
        inputs.push(make_key(VK_SHIFT.0, 0));
        inputs.push(make_key(VK_END.0, 0));
        inputs.push(make_key(VK_END.0, KEYEVENTF_KEYUP.0));
        inputs.push(make_key(VK_SHIFT.0, KEYEVENTF_KEYUP.0));

        for ch in target_path.encode_utf16() {
            inputs.push(make_unicode(ch));
            inputs.push(make_unicode_release(ch));
        }

        let n = SendInputFn(&inputs, std::mem::size_of::<INPUT>() as i32);
        let total = inputs.len() as u32;
        if n != total {
            warn!("...");
            return false;
        }
        info!("...");

        let focused_hwnd = GetFocus();
        if let Some(uia) = automation() {
            if let Ok(elem) = uia.ElementFromHandle(focused_hwnd) {
                let aid = current_automation_id(&elem);
                let name = current_name(&elem);
                info!("... aid='{aid}' name='{name}'");
                if aid == "1001" || name.to_lowercase().contains("file name") {
                    warn!("... Consider H2 fallback.");
                }
            }
        }
        true
    }
}
```
