        status: "ok",
        uptime_secs: 0,
        last_ping_received_ts: 0,

    state.mark_first_push_received();

        status: "ok",
        uptime_secs: 0,

### R-2 (MUST-FIX):§5.2 `set_current_path` AFTER 缺 `ts` 计算

**位置**:v2 plan §5.2 line 451

**v2 §5.2 写法**:
```rust
pub fn set_current_path(&self, p: String) {
    let mut guard = self.current_path.lock().unwrap_or_else(|e| e.into_inner());
    *guard = p;
    self.last_ping_received_ts.store(/* ts */, Ordering::Relaxed);
    // v0.5.5: always mark first push as received when path is set
    // (defense in depth — early-return branch in http_server ALSO marks
    // explicitly, but this covers any future callers of set_current_path).
    self.mark_first_push_received();
}
```

**实际当前 source**(`state.rs:89-98`):
```rust
pub fn set_current_path(&self, p: String) {
    let mut guard = self.current_path.lock().unwrap_or_else(|e| e.into_inner());
    *guard = p;
    // Track that we received a ping — used by /health.
    let ts = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|d| d.as_millis() as u64)
        .unwrap_or(0);
    self.last_ping_received_ts.store(ts, Ordering::Relaxed);
}
```

**问题**:`/* ts */` 是占位符,实施时**会编译失败**(`u64` 期望具体值,不能是 `/* ts */` 注释)。

**修正**:
```rust
pub fn set_current_path(&self, p: String) {
    let mut guard = self.current_path.lock().unwrap_or_else(|e| e.into_inner());
    *guard = p;
    // Track that we received a ping — used by /health.
    let ts = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|d| d.as_millis() as u64)
        .unwrap_or(0);
    self.last_ping_received_ts.store(ts, Ordering::Relaxed);
    // v0.5.5: defense in depth — mark first push as received
    // (early-return in http_server ALSO marks explicitly, but this covers
    // any future callers of set_current_path).
    self.mark_first_push_received();
}
```

### 3.1 §6.2 unit test B-1 regression test 不测 production guard

v2 plan §6.2 line 735-744:
```rust
#[test]
fn mark_first_push_via_early_return_path() {
    let state = AppState::new("".into(), 1);
    state.set_current_path("C:\\".into());
    let prev = state.get_current_path();
    assert_eq!(prev, "C:\\");
    state.mark_first_push_received();   // ← 显式调
    assert!(state.has_first_push_received(), ...);
}
```

**问题**:
- 这个 test 直接调 `state.mark_first_push_received()`,**没验证 production guard 的实际行为**
- 应该模拟 http_server.rs 的 early-return path:

```rust
#[test]
fn http_server_early_return_marks_flag() {
    let state = AppState::new("".into(), 1);
    state.set_current_path("C:\\".into());  // 模拟 init state

    // 模拟 http_server.rs early-return 分支:
    //   let prev = state.get_current_path();
    //   let path_unchanged = prev == path;
    //   if path_unchanged {
    //     state.mark_first_push_received();   ← production 代码
    //     return ...;
    //   }
    let prev = state.get_current_path();
    let path = "C:\\";  // same as init
    let path_unchanged = prev == path;
    assert!(path_unchanged, "should hit early-return branch");

    // Production behavior (this is what http_server should do)
    if path_unchanged {
        state.mark_first_push_received();  // production explicit mark
    }

    assert!(state.has_first_push_received(),
            "early-return branch MUST mark flag (B-1 regression test)");
}
```

**或者更彻底**:**让这个 test 调用 `handle_set_path` 的内部逻辑**(refactor 提取)。

**但 v2 plan §6.2 测试是 inline simulation,可接受**(测试 atomic 的 API,不测试 integration)。
