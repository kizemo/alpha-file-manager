**建议**:v3 plan §5.6 新增 Fix G-文件 5:

### P-3 (轻):v3 §5.7.2 main.rs 注释与 else-if 条件不严格匹配

**位置**:v3 plan §5.7.2 line 318

```rust
} else if !initial_path.is_empty() && initial_path != current {
    // v0.5.5: skip path (first push not received OR initial_path matches current)
    log_event(&Event::SpikeError {
        kind: "opened_write_back_skip_sentinel".into(),
        message: format!(
            "dialog path='{}' current='{}' (sentinel or no-op); skipping until first push received",
            initial_path, current
        ),
        ...
    });
}
```

**注释说**:"first push not received OR initial_path matches current"
**条件**:`!initial_path.is_empty() && initial_path != current`

**问题**:
- 当 `initial_path.is_empty() = true` → 条件 false → 不进 log
- 当 `initial_path != current = false`(matching)→ 条件 false → 不进 log
- 当 `first push not received`(且 A=true, B=true)→ 进 log

注释列了 2 触发条件,但代码逻辑是"first push not received(主要情况)"。`initial_path matches current` 实际是 NO-OP(no log,silent skip)。

注释"OR"是误导 —— `initial_path matches current` 不会触发 log,但注释说会。

**建议**:改注释更精确:
```rust
// v0.5.5: skip path (first push not received — the only "interesting" skip
// that needs diagnostic). initial_path empty / matching current are silent
// no-ops (already excluded by should_opened_write_back).
```
