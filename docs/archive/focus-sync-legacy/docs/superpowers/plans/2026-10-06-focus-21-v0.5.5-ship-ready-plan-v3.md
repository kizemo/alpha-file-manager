### 5.7 Fix N-4:**新增 — 提取 `should_opened_write_back` helper**

**采纳 Mavis R2 N-4**。

#### 5.7.1 文件 1:`sigma-listary-spike/src/state.rs`(加 helper)

```rust
impl AppState {
    /// v0.5.5 (Mavis R2 N-4): extracted from main.rs opened_write_back inline
    /// guard. Single source of truth for "should we write state.current_path
    /// to this new dialog?". Production code + unit tests use this same
    /// function, so test changes if production logic changes.
    pub fn should_opened_write_back(&self, initial_path: &str, current_path: &str) -> bool {
        !initial_path.is_empty()
            && initial_path != current_path
            && self.has_first_push_received()
    }
}
```

#### 5.7.2 文件 2:`sigma-listary-spike/src/main.rs:352-385`(改用 helper)

```rust
// === BEFORE ===
let current = state.get_current_path();
if !initial_path.is_empty() && initial_path != current {
    if state.has_first_push_received() {
        // ... write-back ...
    } else {
        // ... skip log ...
    }
}

// === AFTER (v0.5.5 N-4) ===
let current = state.get_current_path();
if state.should_opened_write_back(&initial_path, &current) {
    // ... write-back ...
    let outcome = spike::writer::write_path(...);
    // ... log ...
} else if !initial_path.is_empty() && initial_path != current {
    // v0.5.5: skip path (first push not received OR initial_path matches current)
    log_event(&Event::SpikeError {
        kind: "opened_write_back_skip_sentinel".into(),
        message: format!(
            "dialog path='{}' current='{}' (sentinel or no-op); skipping until first push received",
            initial_path, current
        ),
        ts: now_iso8601(),
    });
}
```

**好处**:
- production + test 共用同一函数 → test 自动 cover production logic
- 未来 production change 自动被 test 验证
- 单一 source of truth
