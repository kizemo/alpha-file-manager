### 1.3 P-3 ✅:v3 §5.7.2 注释与 else-if 条件不匹配

**v3 plan §5.7.2(我之前写的)**:
```rust
} else if !initial_path.is_empty() && initial_path != current {
    // v0.5.5: skip path (first push not received OR initial_path matches current)
    log_event(...);
}
```

**注释说**:"first push not received OR initial_path matches current"
**条件**:`!initial_path.is_empty() && initial_path != current`

**逻辑分析**:
- outer `if state.should_opened_write_back(...)` 已经过滤"first push received" → 进 else-if 表示 first push NOT received
- else-if 条件 `A && B`:`!empty` AND `!= current`
- 当 `A && B` false 时(empty 或 matching)→ else-if 条件 false → 不进 log → **silent no-op**
- 当 `A && B` true 时 → else-if 条件 true → 进 log → **interesting skip**

**结论**:else-if 实际上**只**对"first push not received + initial_path non-empty + non-matching" log。注释说"OR matching current"是错的——matching case 是 silent no-op。

**采纳**:改注释:"only first push not received"。
