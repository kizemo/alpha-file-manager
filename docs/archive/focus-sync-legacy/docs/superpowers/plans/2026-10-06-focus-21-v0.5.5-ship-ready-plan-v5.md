### 1.4 Q-4 ✅(LOW):i32::MIN 哨兵与初值撞车

**问题**:`best_edit_score = i32::MIN`(初值) + `compute_score_for_automation_id("41477") = i32::MIN`(哨兵) → 二者同值,靠**严格大于** `>` 才避免选中 41477。

**采纳**:**改用 `continue` 过滤**(`uia_inject.rs:592` 附近),从架构上根本不让 41477 进竞争:
```rust
if control_type == UIA_EditControlTypeId {
    // v0.5.5 (Q-4): 41477 是 Chromium 地址栏 ComboBox,
    // UIA ValuePattern SetValue 是 APPEND 不是 replace。
    // 写进去会污染地址栏,彻底排除出 best_edit 候选。
    if current_automation_id(&element) == "41477" {
        continue;
    }
    let score = filename_edit_score(&element);
    if score > best_edit_score {
        best_edit_score = score;
        best_edit = Some(element);
    }
}
```

**优点**:
- `i32::MIN` 哨兵不再需要
- `compute_score_for_automation_id` 可去掉 41477 分支(只剩 1148/1001)
- 41477 不进竞争,语义清晰

### 1.5 Q-5 ✅(LOW):Fix I extension 版本跨 minor 跳

**问题**:`package.json:version 0.3.0 → 0.5.5` 跨 2 个 minor,extension 与 sidecar 是独立 release train。

**采纳**:**改 0.3.0 → 0.3.1**(extension 自己的下一小版本)。理由:
- extension 版本号语义 = "扩展本身功能"
- sidecar 版本号语义 = "同步机制"
- 把 sidecar 0.5.5 灌进 extension 会造成"extension 0.5.5 但功能还是 0.3.0 时代"的误导
