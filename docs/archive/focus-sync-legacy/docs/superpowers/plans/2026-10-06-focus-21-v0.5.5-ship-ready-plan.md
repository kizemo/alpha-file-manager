### 5.2 Fix B:`opened_write_back` boolean flag guard(优化 Mavis)

**Mavis 字符串 sentinel 的 false negative**:用户路径真为 "C:\\" (根目录)时,guard 错误阻止。

**优化方案**:用 `AtomicBool` 状态字段代替字符串比较。

**文件 A**: `sigma-listary-spike/src/state.rs:24-72`

**改动**:
```rust
use std::sync::atomic::{AtomicBool, Ordering};

pub struct AppState {
    pub current_path: Mutex<String>,
    pub registry: Mutex<HashMap<u32, DialogInfo>>,
    pub startup_time: Instant,
    pub last_ping_received_ts: AtomicU64,
    pub last_dialog_event_ts: AtomicU64,
    pub uia_healthy: AtomicBool,
    pub session_id: u32,
    pub committed_hwnds: Mutex<HashSet<u32>>,
    pub unsupported_dialog_count: AtomicU64,
    // v0.5.5 (2026-10-06 Mavis + Claude 复盘): tracks whether extension has
    // pushed at least one path. Until this is true, current_path holds the
    // init sentinel ("C:\\"), and opened_write_back MUST skip writing to any
    // dialog (otherwise it would unsolicited-pollute every dialog with the
    // sentinel value).
    //
    // Using a boolean flag instead of string equality avoids false negatives
    // when the user's legitimate path happens to equal the sentinel.
    pub first_push_received: AtomicBool,
}

impl AppState {
    pub fn new(initial_path: String, session_id: u32) -> Self {
        Self {
            current_path: Mutex::new(initial_path),
            registry: Mutex::new(HashMap::new()),
            startup_time: Instant::now(),
            last_ping_received_ts: AtomicU64::new(0),
            last_dialog_event_ts: AtomicU64::new(0),
            uia_healthy: AtomicBool::new(true),
            session_id,
            committed_hwnds: Mutex::new(HashSet::new()),
            unsupported_dialog_count: AtomicU64::new(0),
            first_push_received: AtomicBool::new(false),
        }
    }

    /// v0.5.5: mark first push as received. Called from http_server set_path.
    pub fn mark_first_push_received(&self) {
        self.first_push_received.store(true, Ordering::SeqCst);
    }

    /// v0.5.5: has the extension ever pushed a path?
    pub fn has_first_push_received(&self) -> bool {
        self.first_push_received.load(Ordering::SeqCst)
    }
}
```
