## 0. 修复原则

任何 gate 必须回答:**"如果这个 gate 永远不通过,系统还剩什么可用路径?"**
如果答案是"什么都不剩",这个 gate 就是**功能删除**,不是优化。

**v0.5.5 错配总结**:Fix B + Fix F 共谋 → 关闭唯一兜底路径 → 100% 失效。

**v0.5.6 目标**:保留 Fix A(对元素修复) + 恢复 v0.5.4 兜底能力 + 完整端到端验证。

## 2. 修复改动清单(总 ~15 行)

### 2.1 改动 1:`state.rs:131-135` — `should_opened_write_back` 加 fallback 分支

**位置**:`sigma-listary-spike/src/state.rs:131-135`

**当前代码(v0.5.5,坏)**:
```rust
pub fn should_opened_write_back(&self, initial_path: &str, current_path: &str) -> bool {
    !initial_path.is_empty()
        && initial_path != current_path
        && self.has_first_push_received()
}
```

**新代码(v0.5.6,好)**:
```rust
pub fn should_opened_write_back(&self, initial_path: &str, current_path: &str) -> bool {
    // 1. 无意义写:跳过
    if initial_path.is_empty() || initial_path == current_path {
        return false;
    }

    // 2. 正常路径:extension 已推过真实路径
    if self.has_first_push_received() {
        return true;
    }

    // 3. v0.5.6 fallback:extension 尚未 PUSH 时,仍执行写入
    //
    // WHY: v0.5.5 在此处 gate 之后,Sigma FM Vue runtime TDZ 错误导致
    //      extension PUSH 永远不来,first_push_received 永远 false,
    //      opened_write_back 永远 skip → 用户零同步。
    //      v0.5.4 baseline 的 `current = "C:\\"` + `!target.is_empty()`
    //      兜底能力必须恢复。
    //
    // SAFETY: Fix A 已确保 fallback 写入元素是 1001/1148,不是 41477,
    //         所以 fallback 不会产生 Chromium ComboBox APPEND 副作用。
    true
}
```

**单元测试必须更新**:
- `state::tests::should_opened_write_back_*` 全部加一遍 3 路径:
  - `initial_path==""` → false
  - `initial_path==current` → false
  - `first_push_received=true` → true
  - `first_push_received=false` + `initial_path != ""` + `initial_path != current` → **true**(v0.5.5 → false,v0.5.6 → true)
