## 选题钩子（首段，约 80 字）

```
今年最让我意外的桌面软件更新，是 Alpha File Manager 3.2.1-beta
新加的一个能力：你电脑里的文件，可以被 AI 助手直接读了。

不是把截图丢给 ChatGPT 帮你猜文件名那种。是真的有一个标准的
接口（Model Context Protocol），挂在 localhost 上，AI 问你
"桌面那个目录多大？" 它可以像你自己 cd 过去、du -sh 一样，
直接拿回答案。

这种用法 5 个月前还没法实现，现在随便一个 Claude Code / Cursor
用户都能用起来。本文把它的 6 个能力、3 道安全闸门、以及它怎么
保持"绝不联网""不写你的硬盘"讲清楚。
```

## 第二段 · 这种用法为什么以前没有

```
"AI 读硬盘" 这件事听起来很科幻，但拆开看其实只是三个能力拼起来：

1. AI 助手能理解一套工具调用规范（OpenAI 当年的 function calling，
   Anthropic 后来升级为 MCP 协议）
2. 文件系统愿意暴露一份"只读视图"（不是把整个硬盘打包成 100 GB
   喂给 AI，而是 AI 问什么就回什么）
3. AI 这边能在问之前搞清楚"哪些工具可用"，避免误调

条件 1 是 Anthropic 把 MCP 开源化之后才普及的；条件 2 一直是技术
上能做到但没人做；条件 3 大致等于"客户端 SDK"。三者同时成立，是
2025 年底 / 2026 年初才有的事。

Alpha File Manager 3.2.1-beta 是我目前看到的唯一一个把这三件事
做完整、并且产品化的桌面工具——不是 demo，不是教程 demo，是装上
就能用的 release。
```

## 第三段 · 6 个能力，全是只读

```
打开 Alpha File Manager 的设置 → Experimental，把 MCP server 开关
打开，它会在 localhost 启动一个端口。Codex / Claude Code / Cursor
这种 AI 助手此刻可以问这 6 件事：

| 它能问 | 我能拿到什么 |
|---|---|
| `list_directory` | 一个目录下都有哪些文件和子文件夹 |
| `get_drives` | 这台机器上有哪些盘，剩多少空间 |
| `get_mountable_devices` | 哪些 USB 盘 / 网络共享可以挂 |
| `search_files` | 找一个叫某名字的文件在哪 |
| `get_directory_size` | 一个目录连子目录一共占多少空间 |
| `get_favorites` | 我都收藏过哪些文件 |

6 个里没有一个会动你的硬盘。复制、移动、删除、改名这些不在接口
里——不是默认关，是根本没实现。

实测几个工作流：
- "帮我找找桌面那个拼错的 PDF，文件名大概是 annual_report 之类的"
  → AI 调 `search_files` 一次就回，文件名拼对拼错都不影响
- "这个目录 + 它所有子目录一共占多少" → `get_directory_size` 一次给到
  不用展开一层层 du
- "我想看 Downloads 里哪些文件是上周下的" → `list_directory` + AI 自己
  按 mtime 过滤
```

## 第四段 · 5 道安全闸门

```
给一个 AI "看到" 你的文件，很多人本能是抵触的。Alpha 这边做了
5 道闸门：

1. 只绑 localhost。服务器只听 127.0.0.1，同网段的别的机器连不上
   —— 不是开了"密码"才防，是物理隔离。
2. 第一次开启时随机生成一个访问密钥，每次请求都校验。不是"密码
   存脑子里"，是 token 让你自己看。
3. 网站不能跨域来请求。即使恶意网页跑了你浏览器，它也不能调本地
   这个端口（不是 referer 检查，是 socket 层直接拒绝）。
4. 权限每次重新检查。你在某次调用后关掉某个权限，下一次请求立刻
   拒绝。不是连上时判定一次了事。
5. 调用日志写到用户设置目录的纯文本里。每次调用都被记录（哪个工具、
   何时、是否被允许），你随时可以打开看。

另外注意：只读是真只读。文件管理器自己可以删文件，但 MCP 接口
上没有这个工具——AI 想删也调不到，没有"误删"路径。

这些条款都写在 README 里"Three safeguards, none of them optional"
那一段，不是我替它吹。
```

## 第五段 · 一键配置 6 个 AI 助手

```
传统上，要给 AI 助手配一个新工具，得手抄 JSON 块到它的配置文件
里——> config.toml、claude_desktop_config.json、~/.codex/
mcp.json 等。一行括号写错，整个助手告诉你 "no servers configured"，
错误还指不到那行括号上。

Alpha 直接在面板里：
- 自动扫描你这台机器上装了哪些 AI 助手（Codex / Cursor / Claude
  Code / Claude Desktop / OpenClaw / Minimax Code 这 6 个）
- 每个助手点一个按钮，它会把正确的 entry 写进对应的配置文件
- 写入前先备份那个文件
- 删开关也对称——再点一次就撤掉，不会污染原来的配置

6 个助手，6 个一键按钮。我在 Cursor 里测了一下，从开 MCP server
到 Cursor 能调，30 秒不到。

这种"我已经知道目标格式是什么"的体验，比"请你帮我读 README
然后填 JSON"的好太多。
```

## 第六段 · 别的细节改进（不是 AI 钩子，但顺手升级了）

```
3.2.1-beta 的 MCP 是新故事，但这个 fork 之前几周已经在做不少
"日常细节"的事：

- 对话框跟着你走：在 Alpha 里翻到目标目录，去任何软件点保存 /
  打开，弹出的对话框已经在那里了。这条最惊喜。
- 真的文件夹树：资源管理器左边那栏叫"快速访问"，其实是历史
  记录。Alpha 这条树跟文件系统 1:1，跟着当前面板走。
- 拼错字也能搜到目录文件：拼错、词序反、漏了扩展名都能命中。
  我们测过一个 1TB 的硬盘，索引后搜索约 2 秒。
- 批量改名不搞破坏：撞名的情况会提前拦下，规则预览实时可见，
  最近 10 次可撤销。这个不是新功能，但是"撞名不悄悄盖"的默认
  行为——别的工具很多都悄悄盖。
- 缩略图能调大小：4 档（32/48/64/80px），行高跟着变，列表不
  错位。缩略图按需生成，只在可见区域渲染。
- 标签页会记住，下次启动直接回到原处；分屏对比 / 传文件 /
  同步用。
- 选中按空格直接预览图片、视频、PDF，不用切别的程序。
```

## 第七段 · 怎么装

```
两个下载途径：

1. 主下载（推荐）：
   https://www.aiec.fun/alpha-file-manager/
   永远指向最新版本，带 SHA-256 校验。

2. GitHub Releases 兜底：
   https://github.com/kizemo/alpha-file-manager/releases
   每个 release 都附 SHA-256 + 安装包链接。

安装包没做代码签名，所以 Windows 会弹"未知发布者"。点"更多信息
→ 仍要运行" 就行。如果你想做 hash 校验，cmd 里：

   certutil -hashfile AlphaFileManager_3.2.1_x64-setup.exe SHA256

跟 Releases 页面上的对照一下，一致就放心。

支持：Windows 10/11 x64、Linux（Flatpak）。

免费开源。
```

## 末段 · 这件事的判断

```
如果你受够了：

- "明明记得文件在哪却找不到"
- "关掉重开标签全没了"
- "预览窗格看不了 PDF"
- "AI 跟我说它不能读硬盘只能看截图"

上面这几条都在 Alpha 里。

它是不是真的完美替代品，要看你工作流。但至少是个"值得装上
试两周"的开源工具。不合适就卸载，没注册账号没强绑什么。

如果你只是想要那个 MCP 接口，可以跳过主体功能把它当成一个
"AI 读硬盘的 mini 工具"。但大概率你会留下来用它的别的东西。

—— kizemo
2026 年 10 月
```
