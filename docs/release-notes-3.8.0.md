## Alpha File Manager 3.8.0

### 新增

- **「档案纸档」主题第二轮细化**：暖纸浅色 / 暖纸深色两套主题全面升级 —— 主区调亮降饱和、图标统一改为浅米色线条、目录图标改用低饱和绿点缀、未激活标签降亮并加浅米灰边线、目录行与文件行底色区隔。
- **工具栏按钮按功能族分色**：右上角按钮区分分屏 / 目录树 / 信息 / 比较 / 更多 / 扩展 / 搜索 / 新建 / 过滤；地址栏左侧的后退、前进、上级、位置、刷新、视图、缩略图各自独立配色。颜色由对比度求解器按各主题标题栏底色算出，保证非文本图标对比度不低于 3:1。
- **列表标题栏层次**：加深底色并加上下边线，列头信息与内容区拉开距离。
- **标签页宽度自适应**：标签宽度随标题内容伸缩，并设最大宽度，标题过长时以省略号截断，不再一律固定宽度。
- **应用图标重新设计**：暖纸配色 —— 深色侧边栏用「浅文件夹 + 深墨 α 字形」，安装器与任务栏用「深墨文件夹 + 浅纸 α」。

### 修复

- **「路径同步」插件在安装 / 升级后失效**：安装器的卸载前钩子会主动禁用插件的计划任务，而安装后钩子只负责启动、不负责启用，导致任务始终处于禁用状态、侧车进程起不来。现在安装流程会先重新启用计划任务再启动，插件在升级后即可正常工作。
- **插件安装脚本写入乱码标题**：安装脚本里的中文破折号在部分系统上被按本地代码页解析，扩展列表里的标题会显示成乱码。现在脚本源文件改为纯 ASCII，破折号在运行时生成，并会就地修正已写入的乱码标题。

### 备注

- 若升级后「路径同步」插件仍未工作，重启一次应用即可恢复。
- 本次改动只涉及界面配色、布局与安装脚本，未改动数据目录结构，无需迁移已有配置。
