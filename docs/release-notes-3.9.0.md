## Alpha File Manager 3.9.0

### 新增

- **应用图标整套重设计（方案 A）**：品牌图标按新方案重画，整组字形做仿射放大（k = 1.21315）并在垂直方向下移字符，使图标在任务栏、安装器等小尺寸下依然饱满可辨；同时输出浅色 / 深色双配色（浅米文件夹 + 深 α、深墨文件夹 + 浅 α），界面深色侧边栏与安装器 / 任务栏各取其一。
- **字体大小三档**：设置 → 外观新增「字体大小」下拉，提供「默认 / 大 / 特大」三档，分别比当前字号增加 0 / 2 / 4 像素（绝对偏移，非比例缩放），行高同步适配；右侧属性栏文字在「大」及以上档位一并放大。
- **设置「关于」页**：设置页新增「关于」分类，显示应用图标、名称与当前版本号，并提供更新日志、GitHub 项目主页 / 提交记录 / 问题反馈、作者与版权、站点链接与微信公众号二维码。
- **收藏夹拖拽排序**：收藏夹管理的分类与收藏项现支持拖拽排序，也可用上下按钮调整顺序；顺序写入用户数据，重启后保留。
- **目录树 tooltip 本地化**：目录树按钮的「显示目录树 / 隐藏目录树」提示完成 17 个语言包的翻译，不再固定显示英文。
- **标签栏宽度分档**：标签宽度按标签数量分档调整（超过 10 个 76px、7–10 个 88px、其余 100px），标签过多时出现左右滚动按钮。

### 修复

- **同版本重装不再被静默拦截**：安装器的早期守卫原以「版本号」作为判据，同版本重装会被守卫直接退出（退出码 10），用户表现为「双击安装包没反应」。现改为比对构建身份（安装包 SHA256），同版本可正常覆盖安装，降级由直接退出改为继续安装。
- **强制结束应用后不再崩溃**：进程被强杀后可能残留没有活着的父进程的 msedgewebview2.exe，WebView2 数据目录被锁住，下次启动会触发 WindowsError(0x800700AA) 崩溃。现已在启动时清理这类孤儿进程。
- **暖纸主题右上角图标改为低饱和度红**：暖纸主题导航器右上角的分屏、目录树等图标此前饱和度过高，与「档案纸档」的整体调性不符，现统一改为低饱和度红。
- **暖纸设置页白色区块改浅米色**：设置页各卡片原为纯白，现改为浅米色，与暖纸主题的纸面底色一致。
- **暖纸地址栏 / 目录树 / 标签文字加深**：这几处前景色在纸面底色上偏浅、对比不足，现已加深。
- **跃动活力主题设置页开关改紫色系**：开关的打开态原为与主题不协调的配色，现改为紫色系。
- **激活标签补上可见边线**：当前激活的标签此前缺少边界标识，在多标签下不易分辨，现已补上。
- **目录树只显示目录**：目录树不再混入文件条目，只保留目录节点。

### 备注

- 本次改动涉及图标资产、主题配色、设置项与安装器判据，未改动数据目录结构，无需迁移已有配置。
- 暖纸两套主题本轮起使用衬线字体族，加粗权重（700 / 800）一并归入衬线族，不再回落到无衬线字体。
- 三套主题（暖纸浅色 / 跃动活力 / 冷杉）的导航按钮配色统一；跃动活力主题去掉了彩虹式分色（色相跨度由 201° 收到 2.5°，目录卡由 149.7° 收到 2.4°）。
- 单一类型的目录不再渲染分类行；仪表盘新增订单控件并更换暖纸顶图。
- 后台轮询间隔放宽（剪贴板监听 400ms → 1000ms，状态栏 5000ms → 10000ms），空闲时的资源占用更低。
