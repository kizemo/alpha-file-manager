## Alpha File Manager 3.24.0

### 新增

- **检索可以限定在某个网盘目录里**：指名某个网盘文件夹的检索请求以前直接回一份空列表，
  因为这条路只遍历本地磁盘。现在作用域会拿网盘索引来解析，一个网盘目录可以单独检索。
  开工前先查四道前置条件，缺哪一条就说明是哪一条：路径得是网盘路径、调用方得说明
  网盘索引在哪、索引得已经建好、这个网盘得勾上参与全局检索。
  文件浏览器里的递归检索仍然只走本地磁盘，不走这条通道。

- **应用日志现在会说清 Focus Sync 侧车在干什么**：日志以前只有一行「侧车已启动」，
  分不清是侧车根本没起来、起来的是另一个版本、还是侧车正常但扩展从没写过路径。
  现在日志里带着侧车自己的回答：版本、模式、扩展是否活着、有没有写过路径、多久没被看见。
  侧车与扩展版本不一致时会记一条告警，过期的内置侧车一眼就能看出来。这条只是告警，
  应用照常启动。

### 修复

- **方向键重新归搜索结果列表所有**：全局检索面板开着时按上下键，移动的却是面板背后
  文件浏览器里的选中项，面板还在，但焦点在第一次按键时就跑了。现在这两个键归结果列表：
  逐行移动，停在首行与末行，背后什么也不动。只有面板开着、焦点在面板里、
  且不在输入框时，结果列表才接管这两个键。

### 变更

- **中文关键词检索快了一大截**：关键词在文件名里的匹配要扫一遍索引的整个词项词典，
  现在这段扫描改成按索引分段并行。在大索引上，中文检索里「匹配」这一段从大约 0.6 秒
  降到大约 0.13 秒；命中集合逐条不变，不用重建索引，也不用重新扫描任何文件。
  命中上万个名字的检索仍然比命中少量名字的慢，剩下的开销在命中词的倒排表上，还在继续查。

### 备注

- 本次未改动数据目录结构，已有配置无需处理。
- 网盘索引的格式没有变化，已有的索引继续可用，不需要重建。
- 已经添加好的网盘连接不受影响，继续用即可。
- 其余 13 个非中英语种的更新日志仍停在 3.22.0 —— 这是已知的语言覆盖缺口，本版未处理。
- 完整清单见更新日志。
