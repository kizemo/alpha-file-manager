## Alpha File Manager 3.24.1

### 修复

- **递归检索跑不起来时会明说**：在网盘目录里检索、或者在不参与全局索引的远程连接里检索时，
  这条通道只能走当前打开的文件夹。以前失败被吞掉，列表安安静静只显示当前层的命中项，
  看上去就像「更深的地方没有匹配」。现在状态栏会带一条告警：「递归搜索不可用，仅搜索当前层」，
  后面跟后端给出的原文原因（文字长的时候完整内容进 Tooltip）—— 对网盘来说，
  就是这个连接没有勾选「加入全局检索」，索引层不可见。当前层的过滤照常生效。
